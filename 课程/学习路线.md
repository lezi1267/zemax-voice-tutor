# Zemax OpticStudio 2023 学习路线(和 AI 助手一起练)

## 上课方式
1. 打开 Zemax(桌面的 Ansys Zemax OpticStudio 快捷方式),把 Zemax 放在主屏
2. 启动助教:`voice-tutor\start.bat`(或桌面「光学设计助教」快捷方式)
3. 要她读数/指路:在 Zemax 点 **编程 → 交互扩展**(小窗留着别关,她会自动连上并驯服它)
4. 对她说:**"开始第 N 课"**
5. 上课循环:
   - 她说这一步做什么(语音,对话小窗里同时有文字)
   - 不想说话就在小窗底部**打字**提问;想打断她念话按 **Esc**
   - 要点的菜单/按钮:屏幕上小幽灵滑过去画**红圈+箭头**指给你看(`guide.py`)
   - 你操作完说"好了",她用 `read_lde` / `read_analysis` / 读屏 OCR **实测**检查,对了进下一步,错了告诉你哪里不对
   - 你明确让她代做时她才动手(`edit_zemax` / `run_optimize` / `scan_param`),动手前自动备份,说"恢复原样"就回滚
6. 验收数字对上她才会记进度(`finish_lesson`);中途退出,下次她会接着上次那一步教
7. API 读不到的内容(赛德尔系数图、图上标注、报错弹窗)她走 OCR 读屏,问"屏幕上写的什么"即可

## 课程表(跟着官方样例练,每课 30-60 分钟)

> 全部 10 课课件已录入 voice-tutor:对她说"开始第N课"即可,课件文件就是本目录的 第N课_*.md。

- [x] **第1课 认识界面,搭出第一个单透镜**
  LDE 镜头数据编辑器、插入面、曲率半径/厚度/材料、设置系统孔径和视场、Quick Focus 自动对焦
- [ ] **第2课 看懂分析图**
  3D Layout、Spot Diagram(点列图)、Ray Fan、OPD,学会判断"这个镜头烂不烂"
- [ ] **第3课 第一次优化**
  评价函数编辑器(MFE)、EFFL 操作数、把半径设为变量、跑 OPT 优化,把单透镜收敛到目标焦距
- [ ] **第4课 消色差双胶合**
  色差从哪来、看懂玻璃图、选玻璃对(A用 BK7/F2 之类),消掉色差
- [ ] **第5课 牛顿望远镜**
  反射系统、坐标断点、卡塞格林/牛顿结构,理解反射镜为什么没有色差
- [ ] **第6课 库克三片式(完整设计流程)**
  从初始结构到优化收敛,体验真实镜头设计的全过程
- [ ] **第7课 像质评价进阶**
  MTF、场曲/畸变网格图、相对照度,学会用指标说话
- [ ] **第8课 公差分析入门**
  公差编辑器(TDE)、敏感度分析,理解"设计得出来"和"造得出来"的区别
- [ ] **第9课 ZOS-API + Python 自动化**
  接入 [ZOSPy](https://github.com/MREYE-LUMC/ZOSPy),让助手直接驱动 Zemax 帮你建模、取数、批量优化
- [ ] **第10课 毕业项目**
  独立设计一个 50mm f/4 双高斯或手机主摄入门结构,我全程只检查不代做
